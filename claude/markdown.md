# Markdown and READMEs

The Configuration repository's `README.md` is the model for every README.

- **Concise:** leave out what any .NET developer already knows, such as what `.editorconfig` or NuGet is. Say where
  things came from and what they do, and write at the final length rather than long then cut.
- **Consistent:** give sections a parallel structure, and use one bullet style throughout: bold label, colon,
  lower-case text.
- **Tasteful:** reference-style links collected at the bottom, tables only where they earn their place, and GitHub
  alerts such as `> [!NOTE]` for asides. No badge walls, emoji headings or decorative formatting.
- **Mechanics:** wrap prose at 120 columns, name the language on every fenced code block, give images alt text, and
  leave no trailing whitespace.
